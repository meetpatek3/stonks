# Ledger Foundation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Scaffold the self-hosted portfolio tracker monorepo and ship a pure TypeScript double-entry ledger with exact money types, deterministic journal ordering, and invariant tests — the foundation everything else replays on.

**Architecture:** pnpm workspace modular monolith. `packages/ledger` is pure domain (no React, no DB). `packages/db` holds Drizzle + Postgres schema (minimal tables for journals/postings in this phase). `apps/web` is a Next.js shell that can boot against Postgres; UI polish comes later. Domain APIs are pure functions over in-memory state so engines are unit-tested without a database.

**Tech Stack:** TypeScript (strict), pnpm, Vitest + fast-check, Postgres 16, Drizzle ORM + drizzle-kit, Next.js App Router (React 19), Docker Compose. HeroUI Pro is wired in a later UI plan; this phase only needs a runnable Next shell.

**Spec:** [`docs/superpowers/specs/2026-08-01-portfolio-tracker-design.md`](../specs/2026-08-01-portfolio-tracker-design.md)

## Global Constraints

- Money never uses IEEE binary floats — integer minor units (`bigint`) in domain and DB.
- Quantities use fixed scale ≥ 8 decimal places (`numeric(28,8)` / scaled bigint in domain).
- Signed amounts are **debit-positive**: asset/expense ↑ = positive; liability/equity/income ↑ = negative.
- Balances are derived by replaying `POSTED` journals ordered by `(trade_date, sort_key, id)`.
- Corrections supersede or reverse; no destructive in-place edits of posted economics.
- `packages/ledger` must not import React, Next, Drizzle, or HeroUI.
- Single household / one ledger; Canada-first tax and HeroUI UI are out of scope for this plan.
- Never invent data; unknown cost basis is a later-phase type but money/ledger APIs must not coerce missing amounts to `0` silently.

```ts
// packages/ledger/src/money/money.ts
import type { CurrencyCode, CurrencyDef } from "./currency.js";

export type Money = {
  readonly currency: CurrencyCode;
  readonly minor: bigint;
};

export function money(currency: CurrencyDef | CurrencyCode, minor: bigint): Money {
  if (typeof minor !== "bigint") {
    throw new TypeError("Money minor units must be bigint");
  }
  const code = typeof currency === "string" ? currency : currency.code;
  return { currency: code, minor };
}

export function add(a: Money, b: Money): Money {
  assertSameCurrency(a, b);
  return { currency: a.currency, minor: a.minor + b.minor };
}

export function sub(a: Money, b: Money): Money {
  assertSameCurrency(a, b);
  return { currency: a.currency, minor: a.minor - b.minor };
}

export function neg(a: Money): Money {
  return { currency: a.currency, minor: -a.minor };
}

export function isZero(a: Money): boolean {
  return a.minor === 0n;
}

export function compare(a: Money, b: Money): -1 | 0 | 1 {
  assertSameCurrency(a, b);
  if (a.minor < b.minor) return -1;
  if (a.minor > b.minor) return 1;
  return 0;
}

function assertSameCurrency(a: Money, b: Money): void {
  if (a.currency !== b.currency) {
    throw new Error(`Currency mismatch: ${a.currency} vs ${b.currency}`);
  }
}
```
